# Nexus — Documentación

Documentación de **NEXUS / SGRSI**, el Sistema de Gestión de Recursos y Servicios de Informática del ITI CEPT. El código vive en [`nexus-iti/gravida`](https://github.com/nexus-iti/gravida) (privado); cada versión tiene su branch `release/vX.Y.Z`.

## Índice

| Carpeta | Contenido |
| --- | --- |
| [`entregas/`](entregas/) | Documentación de cada entrega, ordenada por versión (v0.1.0 → v1.0.0) |
| [`arquitectura/`](arquitectura/) | Decisiones técnicas, inventario de API y migración a capas |
| [`modelo-datos/`](modelo-datos/) | Modelo relacional y MER vigente (Mermaid) |
| [`guias/`](guias/) | Guías de implementación, prioridades, cierre, i18n/temas y correcciones |
| [`despliegue/`](despliegue/) | Despliegue institucional y smoke test LAN |
| [`pruebas/`](pruebas/) | Pruebas automatizadas y casos de caja blanca |
| [`informes/`](informes/) | Informes de correcciones, reevaluación de rúbrica e informe final (PDF) |
| [`diseno/`](diseno/) | Archivo de diseño del prototipo de la 1ra entrega |
| [`prompts/`](prompts/) | Prompts usados en el rework de UI, i18n y temas |

Los documentos se conservan con el texto original de cada entrega. Las rutas internas que mencionan (`docs/…`, `proyecto 3ra entrega/…`) refieren a la estructura del repositorio de código de esa época.
